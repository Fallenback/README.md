## 🚀 Sobre mim

Atuo atualmente como **Engenheiro de Dados**, construindo e mantendo pipelines de dados em ambientes corporativos, com foco em **transformação, orquestração, performance e qualidade da informação**.

No dia a dia, trabalho com:

- 🏛️ **Oracle (PL/SQL)** para modelagem e consultas complexas em ambientes corporativos
- 🔧 **dbt** para transformação e modelagem de dados (ELT)
- 🐍 **Python** para automação, integração e processamento de dados
- ⚡ **Spark** e **Databricks** para processamento distribuído e pipelines em larga escala
- 🌬️ **Airflow** para orquestração de workflows de dados
- ☁️ **AWS** como cloud para armazenamento e processamento de dados
- 📐 Modelagem dimensional em **Star Schema** e organização de dados em **Arquitetura Medalhão** (Bronze, Silver, Gold)

Também utilizo **Power BI** como ferramenta complementar para visualização e análise de dados.

Busco evoluir constantemente em **Data Engineering**, aplicando boas práticas de ETL/ELT, performance e governança de dados.
